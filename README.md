## Abrir el portfolio

Descargá o cloná este repositorio. Desde `portfolio/`, ejecutá `pnpm install --frozen-lockfile` y `pnpm run dev`, con Node.js 24+ y pnpm 11.25.0. Las instrucciones, arquitectura y guía de edición están en [portfolio/README.md](portfolio/README.md). La V2 original sigue disponible en la referencia `v2-base`.

## Versiones

La referencia `v2-base` conserva el punto de partida del portfolio. Los próximos cambios pueden desarrollarse en ramas `feat/...` y revisarse antes de integrarlos en `main`.

Los próximos proyectos pueden agregarse en carpetas independientes, cada uno con su propio README e instrucciones.
