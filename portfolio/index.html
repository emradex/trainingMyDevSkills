CASE / 001 — V.02
EN DESARROLLO

Portfolio personal

Una web para mostrar mi trabajo. Y una oportunidad para trabajar en cómo me presento.

El objetivo

Crear una identidad personal como desarrollador, combinando claridad, criterio visual e interacciones que se puedan probar.

La dirección visual

Negro profundo, tipografía contundente y una combinación de lima ácido y violeta. Una composición editorial con una pieza generativa que responde al puntero.

Lo que funciona hoy

Temas claro y oscuro, español e inglés, escultura interactiva y un experimento de trama regulable. Este prototipo está construido con HTML, CSS, JavaScript y Canvas, sin dependencias externas.

La próxima iteración

Afinar los textos personales, agregar los canales de contacto y preparar la arquitectura en React y TypeScript. Esa migración todavía no forma parte de esta versión.

UN PROCESO ABIERTO. NO UN CASO TERMINADO.
